## v2.5.0（2026-10-01）

> **这个版本修复国际版（AI 区域）的三个用户可见问题**，全部来自 [#19](https://github.com/dingminhua/dsh-connect-trae/issues/19) 的报告：模型取不全、付费会员的订阅状态显示错误、以及调用部分模型时一句看不懂的报错。三个问题都在真实账号上逐条定位并复现过（取证见 `docs/ISSUE19_DIAGNOSIS.md`）。

### 新增

- **国际版模型目录读取全部「货架」**：Trae 把模型清单按 function 分组存放（实测 `solo_agent` 组 19 个、`solo_agent_remote` 组 10 个），而插件此前**只读后者**——报告人 IDE 里能看到、插件里却没有的 `GPT-6-Astra`、`GPT-5.6-Sol/Terra/Luna`、`GPT-5.5`、`GLM-5.2` 等**恰好全部在没读的那组**。现在全部组都请求并合并（同一模型只出现一次）。
- **发现面变宽、调用面保持真实**：排查发现模型**只能通过列出它的那个通道调用**——`solo_agent` 目录有求必应地列出 43 条，但拿它当调用通道时所有模型一律被拒（错误码 `4011`）。因此调用路由表同步修正：新可见的模型经由真正可调用的通道去调，`solo_agent` 从调用表中移除。

### 修复

- **付费会员被显示为「暂无有效套餐」**：卡片此前只看 `has_package`（是否存在套餐权益对象），而付费会员可以**有档位、没有套餐行**——报告人的账号正是如此。现在同时读取 Trae 返回的权威档位字段 `user_pay_identity_str`：你的套餐行应显示「**已有有效套餐 · Pro**」，免费账号也会明确写出「暂无有效套餐 · Free」而不是只给一个布尔。只有精确的 `Free` 算免费；不认识的档位名按付费处理（把付费会员错标成免费是伤害更大的错误）。
- **订阅门禁被吞成 `Stream ended without finish_reason`**：Trae 对超出当前档位的模型返回的其实是「该模型需要订阅」（错误码 `1005`，所需档位在 `extra.plan`），但旧实现把这个信息在流中途弄丢，只剩一句像网络故障的报错、还会被反复重试。现在这类拒绝会被翻译成**如实的错误**——`1005` → `402`（需要付费档，附档位与错误码），其余（`4011` / `4001` / 未知码）→ `400`，Trae 的原始文案也保留在报错里。输出已经开始后才到来的拒绝同样以可读错误终止，不再裸截断。
- **登记两个此前不认识的错误码**：`1005` = 订阅门禁；`4011` = 该通道不提供此模型（它自报的文案声称 rate limit，有误导性）。

### 测试

- **全仓 373 → 392（+19）**：bridge 错误翻译 11 例（含「输出已开始后拒绝」的流中场景，用分块流构造——单块答复会被窥探一起解码，测不到该路径）、卡片订阅行 5 例（渲染真实卡片断言档位文案）、usage 档位保留 2 例、目录 union 1 例，另有既有断言随行为更新。
- **变异验证 5 次全部被抓**：分类忽略 1005 → 2 例失败；plan 提取禁用 → 4 例失败；窥探失效（打回旧行为，即本次要修的 bug）→ 4 例失败；档位恒判免费 → 2 例失败；union 退回单组 → 3 例失败。恢复后 45 文件 392 例全绿。

### 升级

```sh
dsh plugin add dsh-connect-trae        # 或在插件市场更新
```

装好后**重启 DSH**，并在插件卡片 → 国际版 tab **刷新一次模型目录**（新出现的模型来自实时目录，旧目录不会自动带上）。如果你的 DSH 是 0.2.0 系列（含 rc），无需动宿主。
