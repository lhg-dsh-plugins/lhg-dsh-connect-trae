## v2.4.0（2026-09-29）

> **这个版本修好了一个会让插件在 DSH 0.2.0-rc.1 上完全不加载的问题。** 如果你装的是 2.3.1 或更早，并且把 DSH 升级到了 0.2.0 的预发布版，插件此前可能已经「凭空消失」——模型选择器里没有 `trae` / `trae-global`，设置卡片不见，用量路由 404。升级到本版即可恢复。

### 新增

- **识图能力跟随 Trae 自身的多模态标注，不再要求逐一手勾**（[#16](https://github.com/dingminhua/dsh-connect-trae/issues/16)）：Trae 把某个模型标为多模态时，插件直接按多模态对外声明。判据是「**你手动勾选的 ∪ Trae 标注多模态的**」：
  - Trae 明确标为非多模态、或未标注的模型**保持纯文本**，你仍可照旧手动为它们打开图片输入；
  - 你已有的勾选**永不撤销**——上游后来不再标注也不会把已工作的配置打回纯文本；
  - 卡片上被自动开启的行显示为**已勾选且只读**并说明原因。并集语义下取消勾选会被立刻加回，给它一个可点的框是在撒谎；
  - **自动开启 ≠ 自动发图**：它只让 DSH 允许给该模型附图，图片始终由你在对话里自己贴。
  - 本机实测（实时目录 15 个模型、零勾选）：8 个自动获得图片输入（`Doubao-Seed-Evolving`、`Doubao-Seed-2.1-Pro`、`Doubao-Seed-2.1-Turbo`、`deepseek-v4.1-flash`、`kimi-k3`、`minimax-m3`、`qwen3.8-max`、`qwen-3.7-plus`）；Trae 明确标 `false` 的 4 个（`glm-5.3`、`glm-5.2`、`DeepSeek-V4-Flash-Official`、`DeepSeek-V4-Pro-Official`）**正确地保持纯文本**。

### 修复

- **插件在 DSH 0.2.0-rc.1 上整个不加载——peer 上界 `<0.2.0-0` 把 0.2.0 的预发布线一起挡掉了**：
  - **现象**：升级宿主后插件「凭空消失」。不是某个功能坏掉，是 bundle 从未挂载——DSH 自 0.1.7-rc.1 起有一道 **bundle 级 peer 门禁**，peer 范围不满足的 bundle 会被**整体跳过**，只往 stderr 写一行。
  - **根因**：`>=0.1.7-rc.1 <0.2.0-0`。SemVer 里 `0.2.0-rc.1 < 0.2.0-0`，所以这个上界本意是「排除 0.2.0 正式版」，实际把**整个 0.2.0 预发布线**也一并排除了。
  - **修法**：8 条 peer 上界改为 `<0.3.0-0`——放行 0.1.7 与 0.2 两条线（含各自的 alpha/rc），仍挡住未审查的 0.3 线。已用宿主自己发行的门禁代码复验：0.1.7-rc.1 / 0.1.7-rc.2 / 0.2.0-alpha.1 / 0.2.0-rc.1 / 0.2.0 / 0.2.9 全部放行，0.3.0-rc.1 / 0.3.0 仍被拒绝。
  - **不是 0.2.0 破坏了契约**：逐符号核对确认插件消费的 API 全部未变（`resolveRetryPolicy`、`PiAiAdapter`、`withFileLock`、`writeFileAtomic`、`resolveDshHome`、`AttachmentStore` 的声明逐字一致；触及的包源码逐字节相同）。
  - `devDependencies` 一并升到 0.2.0-rc.1，消除「本地验 0.1.7、用户跑 0.2.0」的错位。
- **`multimodal` 随 `lastCatalog` 持久化**：运行时目录每次保存与启动都从保存的目录重新推导，该字段若不持久化，「自动识图」会在保存或重启后立刻退回手动。
- **README「暂不支持」表格过期**：`deepseek-v4.1-flash` 上游已开放到 SOLO 通道（带 `wireFunction: solo_work_remote`，实测刷新确认可调用），已从表中移除；其余 3 个（`glm-5.3-flash`、`kimi-k2.8-preview`、`qwen3.8-flash`）实测仍不在目录里，保留。

### 测试

- **新增 22 例 peer 范围回归**（全仓 345 → 367）：逐条断言每个范围**必须**放行 0.1.7 与 0.2 全线、**必须**拒绝 0.3 线，并禁止 `<0.2.0-0` 这种写法回归。**为什么需要专门的测试**：范围写错时 `tsc` 通过、全部单测通过、`pnpm install` 通过、CI 全绿——只有真实宿主会拒绝加载。
- **新增 8 例识图**（367 → 373）：6 例单元覆盖并集的四个方向，2 例端到端走真实插件与 `ctx.llm.listModels()`。
- **变异验证**：peer 守卫 3 次变异全部被抓（改回 `<0.2.0-0` → 10 例失败；去掉上界 → 8 例失败）；识图并集 3 次变异全部被抓（改回仅手动勾选 → 3 例失败含端到端；在推导前剥掉字段 → 端到端精确失败）。

### 升级

```sh
npm install -g dsh-connect-trae@2.4.0   # 或按你的安装方式
```

装好后**重启 DSH**，并在插件卡片上**刷新一次模型目录**（识图标注存在实时目录里，旧目录不会自动带上）。
